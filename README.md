## Architectural Highlights

### 1. Clean URLs & Single-Page Architecture
- No `.html` extensions exposed in any navigation, links, or address bar.
- Clean in-page hash anchors (`#about`, `#banner`, `#lab`, `#bookshelf`, `#mascot`, `#contact`).
- In-page interactive modals for vision simulation and book inspection without navigating away.

### 2. Editorial Scrapbook Aesthetic
- Architectural graph engineering paper background (`#F3F3F3` base, `#E1E1E1` grid) with paper vignette lighting.
- Giant brutalist `PORTF[O]LIO` poster lockup with Sabhaym's portrait cutout in the letter `O`.
- Organic hand-drawn curved arrow with handwritten annotations (`Caveat` font).
- Audio-reactive geometric vector stars (`✸`, `✦`, `♣`) that pulse and rotate in real time.

### 3. Live Web Audio Voice-Reactive Engine
- Real-time Web Audio API frequency analysis (`AudioContext`, `createAnalyser`) with microphone toggle (`MIC: LIVE / OFF / DEMO`).
- 14-segment vertical LED equalizer bar attached directly to the portrait frame.
- Real-time audio energy driving CSS `--mic-energy` for animated red outline glow.

### 4. Vector Bounding Box & Hardware Details
- Red vector bounding box with 8 white resize handles (`vh-tl` to `vh-br`) framing the primary portrait.
- Technical dimensions and real-time audio telemetry tags.
- App-icon tactile skill badges (`AI Agents`, `Py Code`, `TS WebGL`, `CV DSP`, `∑π Math`, `0→1 Startup`).

### 5. Jagged Ripped Black Paper Banner & Marquee
- Jagged torn paper top and bottom edges (SVG vector tear paths).
- Infinite scrolling white marquee track behind a center pop-out portrait with audio-reactive red glow.

### 6. The Lab & Interactive Notebook
- Polaroid project dossiers held down by translucent washi tape strips (`Spark2Ship`, `sabhyam-ai-mcp`, `Neural CV & DSP`).
- Interactive Idea Notebook Cycler with page-flip animation.
- In-page Neural CV Simulator modal with 60 FPS simulated landmark DSP tracking.

### 7. Formative 3D Bookshelf (3 Books)
- Exactly 3 books: *Steve Jobs*, *Zero to One*, *Build, Don't Talk*.
- Physical 3D CSS transforms with vertical spine typography and interactive takeaway inspection modal.

### 8. Digital Twin Chibi Mascot
- Chibi mascot dock with real-time pointer gaze tracking, speech bubble, and emotion trigger chips.
